# Expected Goals Analysis

A football data-analysis project organized around a Jupyter notebook and a bundled Premier League shot dataset.

## Project files

| File | Purpose |
| --- | --- |
| [Group21Code.ipynb](Group21Code.ipynb) | Main analysis notebook |
| [pl_2025_shots.csv](pl_2025_shots.csv) | Shot dataset included with the project |

## Explore the project

Open the notebook on GitHub to inspect the analysis and saved outputs, or download the repository and open it in Jupyter locally. Keep the CSV alongside the notebook.

```bash
git clone https://github.com/AllanBijuGregory2006/expected-goals-analysis.git
cd expected-goals-analysis
python -m pip install jupyter
jupyter notebook Group21Code.ipynb
```

Install any additional packages imported by the notebook before running its cells. A complete, pinned environment is not yet documented.
